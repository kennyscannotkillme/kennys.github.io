# Contributing to HHH / 参与 HHH

Start with the [live demo](https://kennyscannotkillme.github.io/kennys.github.io/HHH/#daily). No installation or account is needed to explore it.

先打开[在线演示](https://kennyscannotkillme.github.io/kennys.github.io/HHH/#daily)，无需安装或注册。

## Useful feedback / 欢迎哪些反馈

- **Clarity:** Can you tell a forecast from an observed result, and a historical simulation from a live record? / **信息理解：** 能否分清预测与实际结果、历史模拟与当期记录？
- **Accessibility:** Report keyboard, contrast, screen-reader or mobile layout problems. / **可访问性：** 键盘操作、对比度、读屏与手机排版问题。
- **Language:** Suggest clearer Chinese or English explanations. / **语言：** 更清楚的中文或英文表达。
- **Data presentation:** Include the page, displayed date, horizon and visible value when reporting a discrepancy. / **数据展示：** 报告差异时请附页面、显示日期、预测期限与具体数值。

[Report a problem or suggest an improvement / 报告问题或提出建议](https://github.com/kennyscannotkillme/kennys.github.io/issues/new/choose)

Please use screenshots of the public demo only. Do not include account information, credentials or private trading records.

请仅附公开演示截图，不要上传账户信息、凭据或私人交易记录。

## Small changes / 小范围修改

The public interface lives in `HHH/`. See the root README for setup and build instructions. For code changes, describe the problem, the change and how you checked it; include before/after screenshots for visible changes. Discuss larger changes in an issue first.

公开界面位于 `HHH/`，安装与构建步骤见根目录 README。代码修改请说明问题、改动和验证方式；可见界面改动请附前后截图，较大改动先通过 Issue 讨论。

Keep dates, units, source labels and unsuccessful validation results explicit. Do not turn pending outcomes into observed results or research estimates into trading recommendations.

保留明确的日期、单位、来源标记与未成功的验证结果，不要将待观察结果写成已实现结果，或将研究估计改成交易建议。

This repository contains the frontend and selected public snapshots. It does not contain the private data/model-generation pipeline. No project-wide reuse license has been granted; check with the author before redistributing code or data.

本仓库包含前端与选定的公开快照，不包含私人数据及模型生成流程。项目尚未授予统一的再使用许可，重新分发代码或数据前请与作者确认。
