时钟为 T=S+lag：信号日 S 之后第 lag 个交易日按复权开盘价进入，按进入日之后第 h 个交易日 T+h 的复权收盘价退出。因此 T+1/T+3/T+5 从进入日后数，不从信号日数。缺少精确日期价格时保持缺失，不平移到其他日期。
研究保持 RESEARCH_ONLY，唯一候选为 E1，当前网页模型不自动替换。即使开发闸门全部通过，也仅能进入另行预注册的新前瞻验证：至少 60 个新成熟日期、跨至少 3 个月，并完成适用的独立审查。这是最低证据门槛，不是自动通过条件。当前核验仅检查已保存证据的完整性，并非正式独立晋升审计。
